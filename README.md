# Fullstack Social App

## 快速开始

```bash
docker compose up --build -d
```

| 入口 | 地址 |
| --- | --- |
| 前端 | `http://localhost` |
| Swagger | `http://localhost:5000/swagger/index.html` |

## 项目结构

```text
.
├── docker-compose.yml
├── .env
├── backend
│   ├── api/
│   ├── realTimeChat/
│   └── realTimeNotification/
└── frontend/
```
